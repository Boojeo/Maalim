# Ma'ālim (معالم)

A guided, video-based learning journey for new Muslims, with grounded explanations, practice scenarios and a human handoff. Built for the Islamic AI Challenge 2026, Track 3 (4–6 Oct 2026).

## Folder map

| Path | Purpose |
|---|---|
| `START_HERE.md` | The one prompt to paste into Claude Code |
| `CLAUDE.md` | Project rules Claude Code follows in every session |
| `PLAN.md` | Full build plan: features, data model, timeline, risks |
| `UI_BRIEF.md` | Design brief and tokens |
| `content/` | Curriculum, verified passages, video list. **Religious content lives only here** |
| `eval/router.jsonl` | Seed test set for the question router |
| `scripts/make_clips.sh` | Re-encodes and cuts the wudu clips with FFmpeg |
| `design/` | Wireframes (add screenshots) |
| `public/videos/` | Web-ready clips (generated by the script) |
| `.env.example` | Environment variables to fill in |
| `SOURCES_AND_COMPONENTS.md` | Required registry of components, sources, models and clips |

## Provenance
Baseline (before 4 Oct 09:00): this skeleton, curriculum map, source list, wireframes, plan. Product code starts at the challenge opening on 4 Oct 2026.

## Run locally (after Phase 1; in Claude Code cloud use the Vercel preview instead)
```
cp .env.example .env.local
npm install
npm run dev
```
